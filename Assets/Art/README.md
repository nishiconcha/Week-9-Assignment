# Pixel Space Shooter Sprites

46 free 32x32 pixel-art sprites by reodesuxz.

- player: 6
- enemy: 8
- bullet: 12
- explosion: 6
- powerup: 6
- asteroid: 4
- planet: 4

Player ships point up; enemies point down. Explosion is a 6-frame animation (strip + GIF, ~10 fps).
Use Point/Nearest filtering, no compression, integer scaling.
Folders: PNG/32x32, PNG/128x128_x4, animation_strips, GIF, spritesheet.png/json.
